# Data

Datasets are not stored in this repository.

## GTZAN
1. Download the GTZAN dataset (10 genres, 100 clips of 30 s each).
2. Extract it so the structure looks like this:

```
data/gtzan/genres/blues/blues.00000.wav
data/gtzan/genres/classical/classical.00000.wav
...
```

Note: GTZAN has known issues (duplicates, mislabeled tracks). See the main README.

## FMA-small (alternative)
Download from the FMA project and place it under `data/fma_small/`.
